The Four HTML Injection Contexts

The same characters mean different things in each context. Understanding which context your input lands in is the first step in every XSS attack and every XSS defence.

1 · Body Context
<p>Hello [INPUT]</p>
A < here starts a new tag. The attacker can inject any tag — <script>, <img>, <svg>, etc. The most direct injection context.
2 · Attribute Value Context
<div title="[INPUT]">
A < here is harmless. But a " breaks out of the attribute value, letting the attacker add new attributes like onmouseover. No angle brackets needed.
3 · Script Context
<script>var x="[INPUT]"</script>
Inside a <script> tag, the browser applies JavaScript parsing rules. A </script> sequence closes the block regardless of quotes. Breaking out here gives immediate JS execution.
4 · Style Context
<style>.x { color:[INPUT] }</style>
CSS is parsed here. Modern browsers cannot execute JS via CSS injection, but data exfiltration via CSS attribute selectors is possible (covered in Module 12).
