Demo 2 — URL Parameter → Nested Object → Pollution LIVE

Real apps parse URL query strings into nested objects. The key __proto__[innerHTML]=payload creates {"__proto__": {"innerHTML": "payload"}}, which deepMerge writes to Object.prototype.

// What the app does:
function parseQuery(search) {
  const obj = {};
  new URLSearchParams(search).forEach((val, key) => {
    const parts = key.split(/[\[\]]+/).filter(Boolean);
    let cur = obj;
    parts.forEach((p, i) => {
      if (i === parts.length - 1) cur[p] = val;
      else { cur[p] = cur[p] || {}; cur = cur[p]; }
    });
  });
  return obj;
}

Defense: Object.create(null) Makes Pollution Irrelevant

Object.create(null) creates an object with no prototype chain at all. Polluting Object.prototype has no effect on it — the polluted property is simply not in its lookup chain.
