Sinks blocked by Trusted Types

innerHTML / outerHTML

Requires TrustedHTML. Most common DOM XSS sink.

document.write()

Requires TrustedHTML.

eval() / setTimeout(string)

Requires TrustedScript.

script.src / worker.src

Requires TrustedScriptURL.

textContent (not blocked)

Always safe. Use instead of innerHTML for text.

setAttribute('class', …)

Non-URL, non-script attributes are not restricted.

Key Insight: TT enforces, doesn't sanitize

Trusted Types forces all innerHTML assignments through a named createPolicy() function. The policy author decides what's safe. A createHTML: s => s pass-through policy defeats the entire purpose — TT just enforces that someone made an intentional decision.

The correct pattern: createHTML: s => DOMPurify.sanitize(s). TT is the enforcement mechanism; DOMPurify is the actual defense.
