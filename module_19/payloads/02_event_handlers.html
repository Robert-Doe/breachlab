A. Universal Fallback Handlers
EVENT ATTRUNIVERSAL
01
<img src=x onerror=alert(document.domain)>
ContextHTML body — src=x always fails (no file named "x"), guaranteeing onerror fires Mechanism2 — Event attribute: onerror fires when resource fails to load BypassesFilters that block <script> but pass <img> Stopped byOutput encoding; CSP without unsafe-inline; attribute sanitizer stripping event handlers OriginThe most commonly seen XSS proof-of-concept after <script>alert(1)</script>. Reliable because the onerror event always fires on a broken src.
EVENT ATTRZERO INTERACTION
02
<input autofocus onfocus=alert(1)>
ContextHTML body — autofocus triggers onfocus automatically on page load Mechanism2 — Event attribute: onfocus fires when element gains focus; autofocus makes this happen without any user action BypassesFilters blocking onerror/onload but not onfocus; script-tag-only filters Stopped byCSP without unsafe-inline; sanitizer stripping autofocus + event handlers OriginZero-click vector — fires immediately on page load without mouse movement or clicks. Critical for stored XSS scenarios where attacker can't control user interaction.

ContextWhen attacker controls content that becomes the body element, or in HTML injection contexts that allow body tag Mechanism2 — Event attribute: onload fires when the document finishes loading BypassesFilters that block img/script but not body element event handlers Stopped byCSP; sanitizers stripping event attributes on body; contexts where body tag injection is impossible OriginUseful when injecting into pages where <body> tag appears later in the document. The first <body> wins in most parsers.
EVENT ATTRZERO INTERACTION
04

Very widely used in bug bounty reports.

C. Handler Obfuscation — Bypassing Event Name Filters
EVENT ATTRENCODING
09
<img src=x onerror=alert(1)>
ContextHTML body — the = sign is HTML-entity encoded Mechanism2 — Event attribute; HTML entity &#x3D; decodes to = before attribute parsing BypassesFilters matching onerror= (with literal equals sign) before HTML decoding Stopped byFilters/sanitizers that decode HTML entities before pattern matching; CSP OriginHTML attribute values allow entity encoding before parsing. The browser decodes &#x3D; to = before evaluating the attribute. Demonstrates why pre-decode checking is mandatory.

Trivially bypasses case-sensitive filters.

D. Rare but Valid Event Handlers
EVENT ATTRFILTER BYPASS
12
<form><button formaction=javascript:alert(1)>X</button></form>
ContextHTML body — formaction on button overrides form action; click required Mechanism3 — URI scheme (javascript:) via formaction attribute BypassesFilters blocking javascript: in href/action but not formaction Stopped byCSP; sanitizers blocking javascript: URI in all navigable attributes Originformaction is a valid HTML5 attribute on button/input type=submit. A filter that only removes autofocus from <input> misses this.
EVENT ATTRFILTER BYPASS
14

ContextHTML body — object element loads an inline HTML document via data: URI Mechanism3 + 1 — URI scheme (data:) loads a sub-document containing a script tag BypassesFilters blocking script/img/svg but passing object element; filters checking data attribute value only for javascript: Stopped byCSP object-src 'none'; sanitizers blocking object element; blocking data: URI in object data Originobject element loads a sub-document. data:text/html creates an inline HTML document. EVENT ATTRFILTER BYPASS
15
<iframe srcdoc="<img src=x onerror=alert(parent.domain)>"></iframe>
ContextHTML body — srcdoc creates an inline same-origin iframe document Mechanism2 + 1 — srcdoc attribute is HTML-entity decoded, then parsed as a sub-document; inner onerror fires BypassesFilters checking the outer attribute value (sees HTML-encoded img) but not simulating the decoding that srcdoc applies Stopped byCSP; sanitizers stripping srcdoc or iframe; blocking event handlers in srcdoc content Originsrcdoc HTML entities are decoded before the sub-document is parsed. This is one layer of entity decoding on top of normal attribute parsing — a classic mXSS surface (see M13).
